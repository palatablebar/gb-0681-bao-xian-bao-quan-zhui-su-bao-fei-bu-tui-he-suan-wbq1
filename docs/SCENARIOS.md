# 样例场景

12份保单，每份都有基础投保与追溯加保。每三份中的第一份撤销指定加保，其他保单10月降低责任。P001全年3650.00元；P002的181、92、92天三段合计5030.00元，补缴1380.00元。脏批额外含完全重复、缺失保费、同版冲突、短行、空行与重复表头。legacy样例含GB18030中文与全角千分位。

## succession.csv 撤销后继

P101在上游加保被撤销后仍有10月加保；P102只到撤销为止。

- 初始：P101 的 `00004` 为 `待重新核验`，整链不可发布；P102 的 `00006` 为 `已撤销`。
- 裁决“重新核验后保留”：P101 分273天按3650、92天按5475两段，应收4110.00元，补缴460.00元。
- 裁决“随上游撤销失效”：P101 全年仅按3650计，应收3650.00元，补退0.00元；`00004` 保留为失效证据。
- 两种裁决的结案版本号、有效区间与补退金额不同；重复发布同一裁决不升版、不新增补退。
